# Тексти сайту — як редагувати

Усі тексти сайту лежать у цій папці. Кожен файл — звичайний текст, його змінюють прямо на GitHub.
Після збереження сайт оновиться сам приблизно за 1–2 хвилини. Сайт: https://praguetour.pages.dev/

## Як змінити текст — крок за кроком

1. Відкрийте **github.com** і увійдіть (Sign in) як **LudmilaPersha**.
2. Відкрийте **github.com/LudmilaPersha/luda-web** → папку **content** → потрібний файл.
3. Справа вгорі натисніть олівець ✏️ (**Edit this file**).
4. Змініть текст.
5. Натисніть зелену кнопку **Commit changes…**, а у віконці — ще раз **Commit changes**.
6. Через 1–2 хвилини відкрийте сайт і оновіть сторінку.

Помилилися? Нічого страшного: GitHub зберігає всі попередні версії, усе можна повернути.

Нове фото: відкрийте папку **pilot2/images** → **Add file** → **Upload files** →
перетягніть фото → **Commit changes**.

## Де що лежить

| Файл / папка | Що на сайті |
|---|---|
| `storinka.md` | великий заголовок угорі сторінки |
| `holovna.md` | «Популярні пропозиції» на головній — список назв програм, по одній у рядку |
| `pro-nas.md` | розділ «Про нас» |
| `kontakty.md` | заголовок і підказка в розділі «Контакти» |
| `catalog/` | каталог: рубрика → підрубрика → програми |

У каталозі: кожна папка — рубрика (файл `_rubryka.md` — її назва, фото, мови),
у ній папки підрубрик (файл `_pidrubryka.md` — назва), а в них — по одному файлу на програму.
Порядок на сайті = номер на початку назви файлу (`01-…`, `02-…`).

## Будова файлу програми

```
---
title: "Назва програми"
photo: "images/назва-фото.jpg"
price: "Ціна - 150 євро/за групу/2 години"
---
> Ціна - 150 євро/за групу/2 години
> Ціна: 220 євро / 4 год.

Перший абзац тексту.

Другий абзац тексту.
```

- Між рядками `---` — «шапка»: назва, фото, ціна на картці. Текст у лапках `"…"`.
  Якщо всередині тексту потрібні лапки — пишіть «ялинки» « ».
- Під шапкою — повний текст програми.

## Правила тексту

| Пишете | На сайті |
|---|---|
| порожній рядок | новий абзац |
| просто новий рядок | перенос рядка в тому ж абзаці |
| `**слова**` | **жирний** текст |
| рядок з `- ` на початку | пункт списку |
| рядок з `> ` на початку | рамка з цінами |
| `[текст](go:2,4)` | посилання на рубрику 3, підрубрику 5 (рахуємо з нуля) |

## Нова програма

Скопіюйте файл схожої програми в ту саму папку, дайте йому наступний номер
(наприклад `25-nova-prohrama.md`) і змініть шапку й текст. Нове фото покладіть у папку
`pilot2/images/` і впишіть його назву в `photo:`.

Якщо програма є в `holovna.md`, а Ви змінили її назву, — змініть назву і там,
інакше сайт не збереться і покаже, яку назву не знайдено.
